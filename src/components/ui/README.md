# Componentes de interface (shadcn/ui)

Os arquivos desta pasta (botão, caixa de diálogo, campos de formulário, abas, tabela etc.) são
componentes prontos da biblioteca [shadcn/ui](https://ui.shadcn.com), gerados pela ferramenta da
biblioteca e usados pelas telas em `src/components/condo`. Eles não foram escritos pelo grupo, por
isso não têm comentários linha a linha; a documentação de cada um está no site da biblioteca.
